## Описание:

Проект "Ecommerce" - создание приложения для организации электронной торговли.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:nikolayvov/Ecommerce.git
```

2. Установите зависимости:
```
poetry install
```

## Тестирование:

Юнит-тесты были реализованы с помощью pytest. Покрытие составляет 92%.

Запустить тесты:

```
pytest .
```

Покрытие:

```
pytest --cov .
```
